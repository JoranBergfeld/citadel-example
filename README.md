Local contract tests and offline containers are not live Azure acceptance.
The approved API Center API has no plan-read interface. After ordinary preflight
and foundation creation, the lifecycle requires a private, evidence-backed human
portal observation of the actual Free plan before explicit runtime resume.
Process approval is not actual resource proof. Task 20 supplies the downstream
acceptance providers; task 21 supplies live cloud proof.
